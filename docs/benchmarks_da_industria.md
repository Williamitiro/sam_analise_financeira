🎯 MODELOS POSSÍVEIS PARA O SAM
OPÇÃO 1: Primeira Mensalidade (Recomendado para Bootstrap)
# PREMISSAS - Adicionar no dicionário principal
'modelo_afiliado': 'primeira_mensalidade',  # ou 'cpa_fixo' ou 'recorrente'
'pct_usuarios_via_afiliado': 0.30,  # 30% vem de influencer/afiliado
'comissao_primeira_mensalidade': 1.0,  # 100% da primeira mensalidade
Como funciona:

Influencer divulga link de afiliado
Usuário assina pelo link
Primeira mensalidade (R$ 69 / R$ 99 / R$ 159) vai 100% para o influencer
A partir do mês 2, 100% para você
Vantagens:

✅ Sem risco (só paga se converter)
✅ Atrativo para micro-influencers (ganho imediato)
✅ Simples de implementar
Desvantagens:

⚠️ Você "perde" MRR do primeiro mês
⚠️ Se churn for alto (7%), pode não recuperar CAC
Matemática:

CAC SEM afiliado: R$ 147 (marketing)
CAC COM afiliado: R$ 97 (primeira mensalidade) + R$ 0 (marketing)
LTV: R$ 1.182
LTV - CAC_afiliado: R$ 1.182 - R$ 97 = R$ 1.085
LTV/CAC: 11.2x (EXCELENTE)
OPÇÃO 2: CPA Fixo (Cost Per Acquisition)
'modelo_afiliado': 'cpa_fixo',
'pct_usuarios_via_afiliado': 0.30,
'comissao_afiliado_fixo': 50.00,  # R$ 50 por conversão (fixo)
Como funciona:

Influencer traz cliente
Você paga R$ 50 fixo (independente do plano)
Cliente fica com você desde o mês 1
Vantagens:

✅ Você mantém receita do mês 1
✅ Previsível (CAC fixo)
✅ Margem melhor
Desvantagens:

⚠️ Menos atrativo para influencer (ganho menor)
⚠️ Precisa pagar mesmo se cliente cancelar no mês 2
Matemática:

CAC COM afiliado: R$ 50 (fixo)
LTV: R$ 1.182
LTV - CAC: R$ 1.132
LTV/CAC: 23.6x (INSANO)
OPÇÃO 3: Recorrente (% por X meses)
'modelo_afiliado': 'recorrente',
'pct_usuarios_via_afiliado': 0.30,
'comissao_afiliado_pct': 0.20,  # 20% da mensalidade
'comissao_afiliado_meses': 12,  # pelos próximos 12 meses
Como funciona:

Influencer traz cliente
Você paga 20% da mensalidade por 12 meses
Exemplo: Cliente plano Trader (R$ 99) = R$ 19,80/mês para influencer
Vantagens:

✅ Alinhamento de incentivos (influencer quer baixo churn)
✅ Modelo de longo prazo
✅ Usado por SaaS grandes (TradingView)
Desvantagens:

⚠️ Complexo de implementar (precisa rastrear por 12 meses)
⚠️ Custo recorrente (reduz margem)
Matemática:

ARPU: R$ 97
Comissão/mês: R$ 97 × 20% = R$ 19,40
Comissão 12 meses: R$ 232,80
CAC COM afiliado: R$ 232,80
LTV: R$ 1.182
LTV - CAC: R$ 949
LTV/CAC: 5.1x (BOM)
🎯 RECOMENDAÇÃO FINAL
Use OPÇÃO 1 (Primeira Mensalidade) pelos próximos 12-18 meses porque:
